Frequently Asked Questions

JavaScript is a high-level, interpreted scripting language that conforms to the ECMAScript specification.

Primitive types: Undefined, Null, Boolean, Number, BigInt, String, Symbol. Structural: Object, Array, Function, etc.

Primitives are passed by value; objects are passed by reference (the reference itself is passed by value).

var is function-scoped and hoisted; let and const are block-scoped and not hoisted; const bindings are read-only.
